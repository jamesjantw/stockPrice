# 股價追蹤工具 (Stock Price Tracker)

一個基於 Google Apps Script 的台股和美股即時價格追蹤工具，提供完整的價格資訊和視覺化走勢圖。

## 📋 專案概述

此工具允許用戶在 Google Sheets 中輕鬆追蹤多支股票的即時價格，包括：
- 台股 (TWSE/TPEX) 和美股 (Yahoo Finance) 整合
- 即時股價、昨日收盤價、開盤價、最高價、最低價
- 可自訂天數的歷史走勢圖 (SPARKLINE)
- 批量更新功能
- 易於分享的 Google Sheets 介面

## 🛠️ 安裝與設定

### 快速開始（推薦）

#### 選項 1: 使用 clasp 命令列工具（開發者）
```bash
# 安裝 clasp
npm install -g @google/clasp

# 登入 Google 帳戶
clasp login

# 複製專案
git clone https://github.com/jamesjantw/stockPrice.git
cd stockPrice

# 建立新的 Apps Script 專案
clasp create --title "股價追蹤工具"

# 推送程式碼
clasp push

# 開啟 Apps Script 編輯器
clasp open
```

#### 選項 2: 手動設定（一般用戶）

### 1. 建立 Google Apps Script 專案
1. 開啟 [Google Apps Script](https://script.google.com)
2. 點擊「新增專案」
3. 將專案命名為「股價追蹤工具」
4. 刪除預設程式碼，複製 `stockPrice.gs` 的完整程式碼

### 2. 設定 Google Sheets
1. 建立新的 Google Sheets 檔案
2. 在試算表中點擊「擴充功能 > Apps Script」
3. 這會開啟 Apps Script 編輯器（如果沒有，建立新專案並連結）

### 3. 初始化試算表（重要！）
1. **在 Apps Script 編輯器中儲存專案**
2. **重新整理 Google Sheets 頁面**
3. 點擊選單列的「股價工具 > 初始化試算表格式」
4. 系統會自動設定完整的格式和範例資料

### 4. 開始使用

#### 基本使用
1. 在 A2 儲存格輸入股票代號（如：2330）
2. 在 B2 儲存格輸入股票名稱（如：台積電）
3. 在 C2 儲存格輸入公式：`=GETSPARKLINE("2330")`
4. 點擊「股價工具 > 更新所有價格」

#### 支援的股票代號格式
- **台股上市**: 4 碼數字（如：2330 台積電）
- **台上櫃**: 4-6 碼字母數字組合（如：6104 創惟）
- **美股**: 標準代號（如：AAPL 蘋果、TSLA 特斯拉）

#### 進階功能
- **新增股票**: 「股價工具 > 新增股票」
- **刪除股票**: 「股價工具 > 刪除股票」
- **清除快取**: 「股價工具 > 清除快取」
- **調整設定**: 編輯「設定」工作表

### 5. 分享與使用
1. 設定分享權限
2. 其他用戶可以複製試算表並使用
3. 每個用戶需要自己的 Apps Script 專案

## 📖 使用說明

### 🎯 核心功能使用指南

#### 1. 初始化設定（首次使用必做）
1. 開啟 Google Sheets
2. 點擊「股價工具 > 初始化試算表格式」
3. 系統自動建立完整格式和範例資料

#### 2. 新增股票
**方法一：使用選單**
1. 點擊「股價工具 > 新增股票」
2. 輸入股票代號（如：2330）
3. 系統自動設定名稱和公式

**方法二：手動輸入**
1. 在 A 欄輸入股票代號（如：2330）
2. 在 B 欄輸入股票名稱（如：台積電）
3. 在 C 欄輸入公式：`=GETSPARKLINE("2330")`

#### 3. 更新價格資料
**即時更新**
- 點擊「股價工具 > 更新所有價格」
- 系統顯示進度並更新所有股票

**單支股票更新**
- 使用公式 `=TWSTOCKPRICE(A2)` 獲取單一價格

#### 4. 檢視完整資訊
更新後，您會看到：
- **D 欄**: 即時股價
- **E 欄**: 昨日收盤價
- **F 欄**: 開盤價
- **G 欄**: 最高價
- **H 欄**: 最低價
- **I 欄**: 更新時間

#### 5. 視覺化走勢圖
- **C 欄**: SPARKLINE 走勢圖
- 預設顯示 30 天歷史資料
- 可在「設定」工作表調整天數

### 🎨 介面特色

#### 條件格式化
- 🟢 **綠色**: 股價上漲（高於昨收）
- 🔴 **紅色**: 股價下跌（低於昨收）
- 自動視覺化漲跌狀態

#### 資料驗證
- 股票代號格式檢查
- 防止輸入無效代號
- 提供輸入提示

### 🔧 進階功能

#### 設定參數調整
1. 點擊工作表下方的「設定」分頁
2. 修改以下參數：

   - **快取時間**: 資料快取分鐘數

#### 快取管理
- **清除快取**: 「股價工具 > 清除快取」
- 解決資料更新問題
- 強制重新從 API 獲取資料

#### 股票管理
- **新增股票**: 互動式新增介面
- **刪除股票**: 確認機制防止誤刪
- 支援台股和美股混合追蹤

### 📊 支援的股票代號格式

| 市場類型 | 格式範例 | 說明 |
|---------|---------|------|

| 台股上櫃 | 6104, 3529, 6669 | 4-6 碼字母數字 |

### ⚠️ 注意事項

#### 使用限制
- Google Apps Script 每日 API 呼叫限制
- 股市休市期間無法獲取資料
- 網路連線問題可能影響更新

#### 最佳實務
- 定期清除快取以確保資料新鮮
- 避免在短時間內頻繁更新
- 設定合理的自動更新間隔

#### 故障排除
- **顯示「無資料」**: 檢查股票代號格式或網路連線
- **更新失敗**: 嘗試清除快取後重新更新
- **公式錯誤**: 確保 Apps Script 專案正確連結
