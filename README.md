# 股價追蹤工具 v2.0 (Stock Price Tracker)

一個革命性的 Google Sheets 應用程式，充分利用 GOOGLEFINANCE 和 AI() 函數，提供台股和美股的即時價格追蹤、智慧分析和投資建議。

## 📋 專案概述

此工具徹底重新設計，使用 Google Sheets 內建函數大幅提升效能和穩定性，包括：
- **GOOGLEFINANCE 整合**: 自動取得台股和美股的即時價格、技術指標
- **AI 智慧分析**: 使用 AI() 函數提供專業的走勢分析和投資建議
- **自訂走勢圖**: GETSPARKLINE 支援從設定表讀取天數參數
- **批量更新**: 一鍵設定所有股票的公式
- **美觀介面**: 條件格式化和進度條顯示

## 🛠️ 安裝與設定

### 快速開始（推薦）

#### 選項 1: 使用 clasp 命令列工具（開發者）
```bash
# 安裝 clasp
npm install -g @google/clasp

# 登入 Google 帳戶
clasp login

# 複製專案
git clone https://github.com/jamesjantw/stockPrice.git
cd stockPrice

# 建立新的 Apps Script 專案
clasp create --title "股價追蹤工具"

# 推送程式碼
clasp push

# 開啟 Apps Script 編輯器
clasp open
```

#### 選項 2: 手動設定（一般用戶）

### 1. 建立 Google Apps Script 專案
1. 開啟 [Google Apps Script](https://script.google.com)
2. 點擊「新增專案」
3. 將專案命名為「股價追蹤工具」
4. 刪除預設程式碼，複製 `stockPrice.gs` 的完整程式碼

### 2. 設定 Google Sheets
1. 建立新的 Google Sheets 檔案
2. 在試算表中點擊「擴充功能 > Apps Script」
3. 這會開啟 Apps Script 編輯器（如果沒有，建立新專案並連結）

### 3. 初始化試算表（重要！）
1. **在 Apps Script 編輯器中儲存專案**
2. **重新整理 Google Sheets 頁面**
3. 點擊選單列的「股價工具 > 初始化試算表格式」
4. 系統會自動設定完整的格式和範例資料

### 4. 開始使用 (v2.0 簡化流程)

#### 🚀 快速開始（推薦）
1. **初始化試算表**: 點擊「股價工具 v2.0 > 初始化試算表格式」
2. **輸入股票代號**: 在 A 欄輸入股票代號（如：2330 或 AAPL）
3. **一鍵設定**: 點擊「股價工具 v2.0 > 更新所有資料」
4. **等待載入**: GOOGLEFINANCE 和 AI() 函數會自動載入資料

#### 📊 支援的股票代號格式
| 市場類型 | 格式範例 | GOOGLEFINANCE 格式 | 說明 |

| 台股上櫃 | 6104, 3529, 6669 | TPE:6104 | 4-6 碼字母數字，自動轉換 |
| 美股 | AAPL, TSLA, GOOGL | NASDAQ:AAPL | 標準代號，自動判斷市場 |

## 📖 使用說明

### 🎯 核心功能使用指南

#### 1. 初始化設定（首次使用必做）
1. 開啟 Google Sheets
2. 點擊「股價工具 > 初始化試算表格式」
3. 系統自動建立完整格式和範例資料

#### 2. 新增股票
**方法一：使用選單**
1. 點擊「股價工具 > 新增股票」
2. 輸入股票代號（如：2330）
3. 系統自動設定名稱和公式

**方法二：手動輸入**
1. 在 A 欄輸入股票代號（如：2330）
2. 在 B 欄輸入股票名稱（如：台積電）
3. 在 C 欄輸入公式：`=GETSPARKLINE("2330")`

#### 3. 更新價格資料
**即時更新**
- 點擊「股價工具 > 更新所有價格」
- 系統顯示進度並更新所有股票

**單支股票更新**
- 使用公式 `=TWSTOCKPRICE(A2)` 獲取單一價格

#### 4. 檢視完整資訊 (v2.0 增強)
更新後，您會看到完整的 12 欄資料：
- **A 欄**: 股票代號
- **B 欄**: 股票名稱
- **C 欄**: 走勢圖 (SPARKLINE)
- **D 欄**: 即時股價 (GOOGLEFINANCE)
- **E 欄**: 漲跌金額 (紅色=跌，綠色=漲)
- **F 欄**: 開盤價
- **G 欄**: 最高價
- **H 欄**: 最低價
- **I 欄**: 成交量
- **J 欄**: AI 走勢分析
- **K 欄**: AI 投資建議
- **L 欄**: 更新時間

#### 5. AI 智慧分析 (v2.0 新增)
- **AI 走勢分析**: 分析近期趨勢方向和關鍵價位
- **AI 投資建議**: 提供買入/持有/賣出的專業建議
- **風險評估**: 包含在投資建議中
- **技術分析**: RSI、MACD 等指標分析

### ⚠️ 注意事項 (v2.0 更新)

#### 📋 使用限制
- **GOOGLEFINANCE**: 受 Google 服務限制，休市期間顯示舊資料
- **AI() 函數**: 需要 Google Workspace 企業版授權
- **網路連線**: 影響 GOOGLEFINANCE 和 AI() 函數運作

- **初始化設定**: 首次使用務必執行「初始化試算表格式」

- **定期檢查**: AI 分析會在公式重新計算時更新

#### 🔧 故障排除
- **顯示「#ERROR!」**: GOOGLEFINANCE 可能暫時無法存取，稍後重試
- **AI 顯示空白**: 檢查 Workspace 授權或網路連線
